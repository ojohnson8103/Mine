**Week 1: **

1.  A data science project has 6 steps. The steps are defining the goal,
    collecting and managing data, building the model, evaluate and
    critique model, present results and document, and finally depoly the
    model.

2.  Some of the most common data science modeling tasks are classifying,
    scoring, ranking, clustering, finding relations and characterizing.

**Week 2: **

1.  The summary() command is a very helpful command to take a first look
    at the data.

2.  There are multiple things you should look at when analyzing data
    including looking for missing values, invalid values, outliers, and
    the range of the data.

**Week 3: **

1.  Linear regression builds a model that has a predicted numerical
    output and is a linear additive function of the inputs.

2.  The function lm() creates a linear model and allows all the
    variables wanted to be included in the model.

**Week 4: **

1.  Classification is an approach for predicting qualitative responses.
    It involves assigning the observation to a category or class.

2.  Logistic regression predicts the probability that an instance
    belongs to a specific category. One example is the probability that
    one defaults with their credit card.

**Week 5: **

1.  Generalized Linear Models (GLMs) generalize the classical normal
    linear model by relaxing some of its restrictive assumptions and
    provides methods for the analysis of non-normal data.

2.  GLMs are easy to interpret and has the option of an offset and a
    weight. Offset is a variable that could have an influence but you
    don’t want to include it in the model, like a correction term.
    Weight is inversely proporational to the variance in the response
    variable.

**Week 6: **

1.  Decision trees are popular models that are simple and easy to
    understand. They can be displayed graphically, however, they don’t
    have the same level of predictive accuracy as better predictive
    models.

2.  The tree() function creates a decision tree model and you can use
    plot() to display the tree in a way that is easy to understand.

**Week 7: **

1.  There are 2 key questions to address in the k-means clustering: how
    to select the optimal number of clusters and how to determine the
    elements in each cluster?

2.  fviz_nbclust() is the function that finds the optimal number of
    clusters. kmeans() and fviz_cluster() help to visualize the data.

**Week 8: **

1.  Communicating and documenting your results are some of the most
    important roles of a data scientist.

2.  Git is a version control system, a tool that tracks changes to your
    code and shares those changes with others. It allows multiple people
    to work on the same file at the same time.
